# 错误记录

## 2026-09-30 · npm 默认缓存目录无写入权限

- 现象：`npm install` 在系统 npm 缓存目录写入时报 `EPERM`。
- 处理：改用工作目录下的 `.npm-cache` 并指定 npm 官方仓库，依赖安装成功。
- 影响：本地受限环境的安装命令需要显式传入 `--cache .npm-cache`。

## 2026-09-30 · 浏览器自动化 CLI 无法直接启动

- 现象：默认 Node 18 不满足当前 Playwright CLI 的 Node 20 要求，切换 Node 22 后又遇到系统目录写入权限限制。
- 处理：改用 Codex 浏览器工具完成页面检查。

## 2026-10-08 · 浏览器测试的闭包引用

- 现象：测试助手捕获旧标签页后重新绑定 tab，助手仍操作旧页面，出现动画等待超时或当前棋盘不变。
- 处理：把目标标签作为助手参数显式传入；每次切换标签后检查当前 UI 再继续。
- 另：浏览器只读 DOM 求值环境不提供 localStorage，存档边界通过独立入口无存档导入、正式页面进度前后对比和已有存档测试复核。

## 2026-10-08 · 草图来源读取与字面替换

- 现象：Windows 的 PowerShell 请求与 curl 在公共关卡存档站点发生 TLS 凭证错误；Node 的标准 fetch 可正常读取，未禁用证书检查。
- 现象：临时试算脚本用字符串替换生成含美元符号的地图代码时，替换文本中的美元加单引号被当成替换占位符，产生语法错误。
- 处理：代码和地图字面文本优先用补丁修改；确需 JavaScript 替换时用返回字面文本的回调，避免替换占位符解释。临时试算脚本已清理，产品源文件未受影响。
