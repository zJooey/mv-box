# 箱子探险队

面向 9～12 岁孩子的单人推箱子益智网页游戏。采用复古街机主题，以暗色地板、带亮边的深色砖墙、橙色箱子和青色目标格区分棋盘元素。使用 Phaser 4.2.1、原生 JavaScript 和 Vite 6 构建，无需服务端或账号。

## 启动

需要 Node.js 18 或更高版本。

```powershell
npm install
npm run dev
```

打开终端显示的本地地址即可游玩。发布静态网页时运行 `npm run build`，将 `dist/` 放到静态托管服务。

## 玩法

- 把所有箱子推到发光的目标格；箱子不能拉动。
- 电脑使用方向键或 WASD；手机使用棋盘下方的方向键。手机页面会压缩关卡信息，较矮的屏幕可向下滚动查看完整操作区。
- 可撤销有效移动、重开本关，或请求当前局面的下一步提示。箱子陷入无解位置时，提示会建议撤销或重开。
- 前 36 关依次解锁，完成后按关卡编号持续生成新关。进度只保存在当前浏览器的本地存储中。

## 关卡与测试

`src/levels.json` 是已预先生成并验证的 36 关。前 12 关使用紧凑的 7×7 地图：前两关单箱入门，第 3 关起加入双箱；第 13～24 关为 9×9 三箱地图，第 25 关起为 9×9 四箱地图。每关按固定种子布置不同的连通墙体，先从完成布局反向构造谜题，再按推动次数与解题步数筛选。`src/solver.js` 用于验关和当前局面的提示；无尽关卡在后台线程生成。

```powershell
npm test
npm run validate:levels
npm run build
```

如需重新生成固定关卡，运行 `npm run generate:levels` 后再运行上述验证命令。本次全部 36 关已重新设计，已有解锁编号仍会保留，但对应谜题会更新；再次重新生成可能改变既有地图，发布后不建议随意执行。

建议在电脑和手机浏览器中分别自测选关、推箱、撤销、重开、提示、过关以及刷新后的进度恢复。游戏新增文件独立于其他应用；项目不包含排行榜、账号或联网存档。

## 已知边界

本地浏览器数据被清除后，关卡进度无法恢复。自动生成关卡经过可解性与推动次数筛选，但趣味性仍需结合实际试玩持续调整。
